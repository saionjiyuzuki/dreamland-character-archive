# DREAMLAND V12.8.0 — Hollow Holds & Economy / Pass

- Single-lane and Multi Hold bodies are now hollow/transparent, keeping only their outline and head so ordinary notes remain visible through them. Multi Hold keeps a phase-aware colored rim gradient.
- Added persistent local player progression: EXP, player level, Coin, Crystal, play count and pass progression.
- Normal completed songs grant Coin, player EXP and pass EXP. AUTO runs do not grant rewards.
- Each player level-up grants 5 Crystal. Each pass tier grants 60 Coin; every fifth tier grants 3 Crystal.
- Added a 10-tier seasonal pass panel and reward progress.
- Added a Coin cosmetic shop with four equipable hold-theme accents.
- Added a Crystal song-license shop. Starter songs remain unlocked; other charts display their Crystal price and require purchase before play.
- Economy data is saved to localStorage in the current browser. It is a local/offline save, not a server account.
- Build and the current test suite pass.
