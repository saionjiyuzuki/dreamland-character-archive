快捷键与操作

空格播放 / 暂停 (暂停时回到开始播放的位置用 Shift+空格)
滚轮 / ↑ ↓按吸附细分前后移动一格
PageUp / PageDown前后一小节；Home / End 跳到开头 / 结尾
Ctrl+滚轮 / + -纵向缩放
[ ]切换吸附细分 (1/4 1/8 1/12 1/16 1/24 1/32 …)
1 – 5选择 / Tap / Hold / Multi / 擦除
D F J K (4K) · S D F J K L (6K) · A S D F J K L ; (8K)在播放线位置的对应轨道放置 Tap；播放中可实时打谱 (按住超过一格生成 Hold)
Tap / Hold 工具单击放置；Hold 拖动设置长度和终点轨道
Multi 工具横向拖动设定覆盖范围，纵向拖动设定长度
选择工具单击选中，Shift/Ctrl 多选，空白处拖动框选；拖动音符移动 (Alt 拖动 = 复制)
选中的长条拖动圆点调整关键帧；双击身体添加关键帧；双击关键帧删除
右键删除音符
← → / Alt+↑ ↓选中音符左右移动一轨 / 前后移动一格
Ctrl+C / X / V复制 / 剪切 / 粘贴到播放线位置
Ctrl+A · Delete · Esc全选 · 删除选中 · 取消选择
M · Q选中音符左右镜像 · 量化到当前细分
Ctrl+Z / Ctrl+Shift+Z撤销 / 重做
Ctrl+S · Ctrl+O · Ctrl+Enter保存工程 · 打开 · 从当前小节试玩

位置格式为 小节:拍:tick，每拍 192 tick。工程每 3 秒自动保存在本浏览器中。
